# Segurança

Obrigado por ajudar a manter o **Fitness Hub** seguro! Levamos a segurança dos dados dos nossos usuários a sério.

## Versões Suportadas

| Versão | Suportada          |
| ------ | ------------------ |
| 0.1.x  | :white_check_mark: |

## Reportando uma Vulnerabilidade

**Por favor, NÃO abra issue pública** para vulnerabilidades de segurança.

Em vez disso, reporte de forma privada:

- **Email:** security@fitnesshub.com
- **Assunto:** `[SECURITY] Descrição curta`

Inclua:

- Descrição da vulnerabilidade
- Passos para reproduzir
- Impacto potencial
- Versão afetada

## Processo de Resposta

1. **Confirmação** — em até 48h úteis
2. **Avaliação** — análise do impacto e severidade
3. **Correção** — patch de segurança em versão privada
4. **Disclosure** — publicação coordenada após o fix

Política de disclosure: 90 dias após o reporte, ou até o fix estar disponível (o que vier primeiro).

## Boas Práticas para Usuários

- Use uma senha forte (mínimo 8 caracteres)
- Não compartilhe sua conta
- Reporte comportamento suspeito
- Ative 2FA quando disponível (em breve)
